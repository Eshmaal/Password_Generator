#  Secure Password Generator

A sleek, responsive dark-mode web application built with HTML, CSS, and JavaScript that generates secure, customizable passwords.

##  Features
* **Custom Length:** Select password length from 6 to 20 characters with live visual feedback.
* **Character Controls:** Toggle uppercase letters, lowercase letters, numbers, and symbols.
* **One-Click Copy:** Quickly copy generated passwords to your clipboard using the modern Clipboard API.
* **Dark Mode UI:** Designed with a modern, developer-friendly dark aesthetic.

##  Built With
* **HTML5:** Semantic structural layout.
* **CSS:** Custom dark theme, flexbox layout, and styled form controls.
* **JavaScript :** Asynchronous logic, character set generation, and DOM manipulation.

## 🚀 How to Run Locally
1. Clone this repository or download the files.
2. Open `pg.html` directly in any web browser.
